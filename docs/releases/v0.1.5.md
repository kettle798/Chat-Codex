Chat-Codex v0.1.5 主要聚焦新版 Codex app-server 协议适配、会话与权限能力对齐、进度/旁白投递稳定性、TUI 模块化，以及 0.1.5 正式发布前的依赖安全修复。

## 安装 / 升级

如果你从 npm 安装，请在 npm 0.1.5 发布后执行：

```bash
npm install -g chat-codex@0.1.5
chat-codex --version
chat-codex
```

## 新增项

- 【新增】适配新版 Codex app-server session/thread 协议，`/sessions` 可继续保持原有交互并使用官方 `thread/list` 能力补充历史会话发现。
- 【新增】`/sessions all` 支持列出本机全部可发现的 Codex 历史会话。
- 【新增】`/sessions cwd` 支持按工作目录浏览历史会话，再选择目录内 session 进行切换。
- 【新增】`/session <id>` 支持查看指定 Codex 会话详情，不改变当前聊天绑定。
- 【新增】`/permission` 对齐官方可见权限模式：Ask for approval、Approve for me、Full Access。
- 【新增】`/goal` 适配新版 Codex Goal 状态，并同步更新 `/help` 说明。
- 【新增】支持 Codex `request_user_input` 聊天侧回答，使用 `/a数字` 选择选项，支持自由文本补充和群聊先答生效。
- 【新增】识别并投递 Codex app-server 连接恢复失败等重要通知，避免只在本机日志里看到连接异常。
- 【新增】引入 Codex 旁白独立投递路径，brief 模式默认可投递 Codex commentary，避免被普通进度节流卡住。
- 【新增】飞书群聊底层协议映射、@Bot 识别、群成员名册和最小权限基础结构；0.1.5 公开版仍暂不开放群聊接收入口。
- 【新增】微信 2.4.4 相关适配，包括 `context_token`、`runId`、typing ticket 和结构化工具进度实验能力。

## 优化项

- 【优化】进度投递模式精简：微信公开保留 `silent`、`brief`；飞书公开保留 `realtime`、`silent`、`brief`。
- 【优化】普通文本进度不再带 `Codex 进度:` 前缀，微信/飞书聊天里只显示进度正文。
- 【优化】TUI/终端仍用 transcript 类型标记“进度”，不再依赖正文前缀判断。
- 【优化】brief 进度在本机日志完整记录，并定期 flush 到渠道，避免只看到第一条摘要。
- 【优化】普通文本进度和结构化工具进度使用独立失败冷却，工具进度失败不再挡住普通进度。
- 【优化】成功发送进度时降低详细日志噪声，失败时仍保留完整 WARN、目标信息和本地 transcript。
- 【优化】`/status` 增加模型、权限、上下文 token、Goal、近期 Codex 通知和 compact 状态等诊断信息。
- 【优化】TUI 拆分 `app.tsx` 主要职责，把输入处理、导航、视图渲染、动作处理和控制器拆到独立模块。
- 【优化】配对详情展示当前绑定的 session 信息。
- 【优化】保留 `/plan`、`/code` 切换时原 session 模型与思考等级，不再因为新会话策略覆盖既有 session 设置。

## 修复项

- 【修复】修复 brief 模式摘要进度后续不持续投递的问题。
- 【修复】修复微信 detailed 模式下结构化工具进度失败会连带压制普通文本进度的问题。
- 【修复】修复启动或切换模式时有概率修改 session 模型思考等级的问题。
- 【修复】修复 app-server reconnect 重要通知只进本机日志、不投递到聊天渠道的问题。
- 【修复】修复飞书群聊能力尚未完成时仍能从公开入口开启的问题；0.1.5 中 `/group`、`/grop` 和 TUI 开关均保持关闭。
- 【修复】升级 `qs`、`form-data`、`protobufjs`、`ws` 等依赖锁定，发布前 `npm audit --omit=dev` 已清零。
