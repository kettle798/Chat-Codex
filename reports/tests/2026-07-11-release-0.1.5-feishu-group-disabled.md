# 测试报告：0.1.5 发布准备与飞书群聊公开入口关闭

## 测试目标

验证 `0.1.5` 发布准备改动：

- 版本号升级到 `0.1.5`。
- 飞书群聊功能保留内部代码，但公开版暂不允许开启。
- TUI 渠道详情隐藏飞书“群聊接收”开关。
- 飞书私聊 `/group on` 和隐藏别名 `/grop on|off` 不再修改群聊接收能力。
- npm 发布前构建、测试、安全审计、打包和发布 dry-run 通过。

## 实际结果

- `npm run build` 通过。
- 定向测试通过：`56 passed, 0 failed`。
- 第一次 `npm test` 发现旧断言仍期待 `ChannelActions.setChannelGroupEnabled(..., true)` 生效；已按 0.1.5 公开版策略改为保持 `group=false`。
- 修复后 `npm test` 通过：`485 passed, 0 failed`。
- 初次 `npm audit --omit=dev` 报 3 个 high：
  - `form-data <4.0.6`
  - `protobufjs <=7.6.2`
  - `ws <8.21.0`
- 执行 `npm audit fix --omit=dev` 后，shrinkwrap 更新到安全补丁版本：
  - `form-data 4.0.6`
  - `protobufjs 7.6.5`
  - `ws 8.21.0`
- 重新 `npm install` 恢复开发依赖后，`npm audit --omit=dev` 结果为 `found 0 vulnerabilities`。
- 安全补丁后再次 `npm test` 通过：`485 passed, 0 failed`。
- 默认 `npm pack --dry-run --json` 因本机 npm cache 下存在 root-owned 文件失败；改用 `/private/tmp/chat-codex-npm-cache` 后通过。
- `npm pack --dry-run --json` 结果：
  - package：`chat-codex@0.1.5`
  - tarball：`chat-codex-0.1.5.tgz`
  - package size：约 `3.48 MB`
  - unpacked size：约 `37.07 MB`
  - entry count：`974`
- `npm publish --dry-run` 通过，内部再次执行全量测试：`485 passed, 0 failed`，最后输出 `+ chat-codex@0.1.5`。
- `npm view chat-codex version --json` 返回当前线上版本：`"0.1.4"`。
- `npm whoami` 返回 `401 Unauthorized`，当前环境没有 npm 登录态，因此未执行真实 `npm publish`。
